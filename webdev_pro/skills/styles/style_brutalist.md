# Style: Neo-Brutalist

- Background MUST be a solid, high-contrast off-white (e.g., #f4f0ec) or pure black (#000000).
- Borders: Use massive, unapologetic borders (`border: 4px solid black`).
- Shadows: NO soft blurs. Use hard, solid offset shadows (`box-shadow: 8px 8px 0px #000`).
- Typography: Massive, tight, uppercase. Use sans-serif fonts like Impact, Space Grotesk, or Helvetica. Overlap text elements slightly.
- Colors: Stick to a strict palette of 2-3 highly saturated colors (e.g., acid green, hot pink) over black/white.
- NO gradients. NO border-radius (`border-radius: 0`).
- Add raw, visible grids or thick marquee borders.
