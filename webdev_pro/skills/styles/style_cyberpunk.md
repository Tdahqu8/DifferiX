# Style: Cyberpunk / Hacker

- Background: Deep black (#050505) with a subtle animated CRT scanline overlay.
- Accents: Neon cyan (#00f0ff) and hot magenta (#ff003c). Use these for text glows (`text-shadow: 0 0 10px #00f0ff`).
- Borders: Thin, glowing lines (`border: 1px solid #00f0ff; box-shadow: inset 0 0 10px rgba(0,240,255,0.3)`).
- Typography: Monospace fonts (Fira Code, Courier) for everything. Add a glitch effect on hover for the main title.
- UI Elements: Sharp corners (`border-radius: 0`), terminal-style input fields.
- Add a terminal-like header or status bar (e.g., `> SYSTEM.ONLINE`).
